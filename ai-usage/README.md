# Tehisintellekti kasutamine

Kui kasutasid tehisintellekti abi, siis faili **prompts.md** kopeeri enda antud promptid ja keelemudeli vastused.

See fail **ai-usage/README.md** täida ära vastavalt enda kasutamisele.

## Kasutatud tööriistad
Näiteks ChatGPT, GitHub Copilot või Cursor. Kui ei kasutanud, siis piisab lausest "Tehisintellekti abi ei kasutatud".

## Milleks kasutasin?
Näiteks ideede leidmiseks, koodi kirjutamiseks, vigade
lahendamiseks või dokumentatsiooni koostamiseks.

## Peamised mõjutatud osad
Nimeta olulisemad failid või funktsioonid, mille loomisel
kasutasid tehisintellekti abi.
